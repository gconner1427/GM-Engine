# Names

The pools the GM draws names from. A name the GM makes up on the spot comes out sounding generated, so every new name in this narrative is drawn from here at random instead (`gm name "<pool>"`), and crossed off so nobody shares it.

Each `##` heading is one pool. Sort them however this world's naming works: by people or region, then given names and family names. Built during setup from sources that fit each people (real records, real languages, the patterns you set), and you strike anything you don't like. Add names any time: one per line, starting with `- `. A crossed-off name has been used.

A name in the engine's `Writing/Banned Names.md` is never drawn.
