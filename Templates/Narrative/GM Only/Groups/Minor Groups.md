# Minor Groups

Groups the narrative has touched that don't need a full doc: one `###` entry each. Read only the entry for a group in the scene. A group that starts acting on its own gets a full doc with `gm add group "<Name>"`.

Entry format:

```
### Name
**Kind:** family, crew, guild, company, cult, government
**Wants:** what it's after
**Who:** the members that matter
**Stance:** how it stands toward the character and toward other groups
- What's happened to it that sticks, one line each, tagged.
```
