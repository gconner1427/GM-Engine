# Minor Places

Places the narrative has passed through or named that don't need a full doc: one `###` entry each. Read only the entry for the place in the scene. A place the character keeps coming back to gets a full doc with `gm add place "<Name>"`.

Entry format:

```
### Name
**What:** what it is and who runs it, in a line
**Layout:** what the page has set
**Has:** what it holds that matters, and anything left here
**Now:** its state right now
- What's happened here that sticks, one line each, tagged.
```
