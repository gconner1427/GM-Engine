# World Notes

Hidden canon about the world itself: what you've established behind the scenes that the character hasn't learned. The secret side of a law, history nobody tells, what's really in the hills. Tagged **[GM]**, or **[Setup]** when the user gave it to you as a secret. When the page shows one, retag it **[S#]** and copy it to the matching doc in `World/`.

Decide these only when play needs them, and write each one down the moment you do, so it holds the next time. Never write over anything in `World/World Bible.md`, and never settle anything under its **Reserved** heading.
