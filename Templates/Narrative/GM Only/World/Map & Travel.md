# Map & Travel

Where things are relative to each other, and how long it takes to get between them. Built at setup for the region the narrative starts in, and extended as the character goes further. Every distance or travel time the page sets is tagged, so the next trip takes the same time. Each place's own doc is in `GM Only/Places/`.
